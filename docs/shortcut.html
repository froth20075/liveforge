Shortcut 1 · “LiveForge Video” — share from Photos

0New Shortcut → ⓘ → enable “Show in Share Sheet”

Name it LiveForge. Set share sheet input types to Media / Videos.

1Action: Receive input from Share Sheet

Added automatically when share sheet is enabled — set type to Videos.

2Action: “Base64 Encode”

Input: Shortcut Input. Tap the action's arrow → set Line Breaks: None.

3Action: “Format Date” (Current Date)

Format: Custom → paste this format string:

yyyyMMddHHmmss

4Action: “Dictionary”

Two entries — key message = forge, key content = the Base64 Encoded variable from step 2.

5Action: “Get Contents of URL”

URL — paste, then tap into it and insert the Formatted Date variable where it says FORMATTEDDATE:

Key: Accept · Value:

application/vnd.github+json

Request Body: JSON → select the Dictionary from step 4.

6“Show Notification” + optional “Open URLs” → Studio

Each shortcut is one recipe. Share any video → LiveForge → it uploads with your recipe baked in, the inbox workflow forges it, and the pair appears under Studio → Downloads (and as a GitHub Release). Download both files, upload them together at icloud.com → Photos, set as wallpaper.

Want different recipes? Duplicate the shortcut, change the toggles above, and paste the new URL — e.g. “LiveForge Noir”, “LiveForge Reverse”.
